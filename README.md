# TechCareer Guide

A responsive, interactive career exploration website built with HTML, CSS, and vanilla JavaScript for a BCA mini project.

## Features
- 12 software/technology career profiles
- Search and filters for role, skill, company, category, salary, and difficulty
- Sortable career directory
- Role detail modal with skills, tools, education notes, and project ideas
- Compare up to four careers
- Save favourite roles using browser local storage
- Beginner learning roadmaps with progress saved locally
- Career-fit quiz with suggested paths
- Official company career-page directory
- Dark/light theme toggle
- Responsive desktop and mobile layout
- Print roadmap support

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. No npm install, API key, or backend is required.

## Publish
You can upload `index.html` to a GitHub repository and enable GitHub Pages from the repository's Pages settings.

## Important data note
Salary ranges are illustrative estimates for a demo and are not live market data or guarantees. Before presenting the project academically or relying on the numbers, research and cite current salary sources and verify employer eligibility and vacancies on official career pages. Company names indicate places to explore, not confirmed current hiring.
